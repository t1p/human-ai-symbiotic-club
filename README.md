# Human–AI Symbiotic Club

Клуб, где люди и AI-агенты исследуют совместимость как элементов единой когнитивной системы.

Сейчас в фазе активного эксперимента: **гипотеза №4 «Узел связи»**.

---

## Что здесь происходит

Участники клуба — практики и исследователи с разными векторами. Общаемся в Telegram-топике. AI-агент (MaymunAI) работает поверх живого потока: суммаризирует, находит пересечения, предлагает связки.

Всё важное фиксируется здесь, в GitHub. Не ради архива — чтобы возвращать в живое пространство.

---

## Гипотеза №4 — «Узел связи»

Проверяем: может ли AI-агент стать узлом связи между участниками — находить неочевидные точки пересечения и предлагать мини-коллаборации, которые реально запускаются.

Подробнее: [hypotheses/hypothesis-04.md](hypotheses/hypothesis-04.md)
Архитектура эксперимента: [experiments/hypothesis-04/architecture.md](experiments/hypothesis-04/architecture.md)

**Окно проверки:** 15–29 мая 2026

---

## Как участвовать

1. Появись в Telegram-топике и обозначь свой вектор — что тебя занимает прямо сейчас
2. Заведи карточку участника: скопируй [шаблон](templates/participant-card.md) в `participants/`
3. Реагируй на предложения связок — "+" если интересно, "не сейчас" если нет
4. Предлагай квесты: конкретная задача + критерий выполнения + дедлайн

Всё добровольно. Нет регламента, которому нужно следовать.

```

Вс       Оркестратор публикует итоги в топик
Пн       Фиксация результатов, старт нового цикла
```

---

## Как AI-агент предлагает связки

Агент Связки читает дайджест недели, извлекает векторы и задачи участников, ищет нетривиальные пересечения. Предложение выглядит так:

```
🔗 Связка: Анна × Михаил
Почему: у Анны задача по валидации гипотезы через пользователей,
        у Михаила — опыт быстрых custdev-интервью
Предложение: 30-минутный звонок, Анна описывает гипотезу,
             Михаил предлагает структуру интервью
```

Если видишь себя в предложении — просто напиши "+" в топике.

---

## Как результат становится артефактом

1. Связка получила "+" от обоих участников
2. Они сделали что-то конкретное (встреча, текст, эксперимент)
3. Кто-то из них фиксирует результат в `experiments/hypothesis-04/`
4. Оркестратор добавляет в следующий дайджест

Артефакт — то, что можно передать и не потерять.
